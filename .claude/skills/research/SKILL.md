# /research – Shopify App Research

Perform structured research for a Shopify app idea.

## Process

1. Clarify the core problem and target merchant segment.
2. Search for existing apps solving the same problem.
3. Analyze top 5 competitors:
   - Pricing model
   - Key features
   - Reviews (what merchants love / hate)
   - Gaps and opportunities
4. Estimate market demand signals.
5. Produce a short recommendation:
   - Build / Pivot / Kill
   - Suggested positioning
   - Minimum viable feature set

## Output Format
- Problem statement
- Target merchant
- Competitor table
- Opportunity gaps
- Go / No-Go recommendation
